# Aturan Frontend EtaCafe

- Satu halaman = satu file di pages/<peran>/. Jangan pindahkan atau ganti nama tanpa diskusi.
- Pemanggilan API hanya lewat src/api/*.ts.
- Tipe data hanya dari src/types/index.ts.
- Komponen yang dipakai lebih dari satu halaman masuk ke components/common.
- Jika memakai AI, tempel dulu isi README ini dan header komentar pada file halamannya.
- Kerjakan di branch sendiri (feat/<nama-halaman>) lalu Pull Request.
